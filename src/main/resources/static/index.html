How It Works

The 5-Stage Agent Loop

Sentinel's OpenAI agent orchestrates a disciplined forensic workflow. Each stage yields verifiable evidence.

1. Inspect Media

Decode container, codec, resolution, frame rate, and bitstream structure. Compute SHA-256 integrity hash.

2. Examine Metadata

Parse EXIF, XMP, IPTC headers. Cross-reference timestamps, GPS coordinates, and camera device fingerprints.

3. Verify Signatures

Validate C2PA manifests, Content Credentials, and PKI certificate chains against trusted roots.

4. Forensic Analysis

Run Error Level Analysis (ELA), splice detection, GAN/diffusion pattern scanning, and compression grid checks.

5. Report Evidence & Uncertainty

Synthesize calibrated uncertainty intervals, narrative explanation, and verified cryptographic trust reports.

Critical Distinction

Missing provenance does not prove a deepfake. Sentinel distinguishes between three states: Verified Modified Unknown — because absence of evidence is not evidence of fabrication.
